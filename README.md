## 📂 Project Structure & Pages
The website consists of 4 fully responsive pages built using HTML, CSS, and interactive JavaScript:
1. **`index.html` (Home):** Landing page featuring the main hub overview and an interactive button redirecting to daily picks.
2. **`top-picks.html` (Top Picks):** Showcases top-tier game recommendations, featuring *Uncharted 2*.
3. **`platforms.html` (Platforms & Specs):** Details hardware requirements spanning original 2009 PS3 specifications up to modern PC remasters.
4. **`about.html` (About):** Background info on the project scope and community focus.
5. **`style.css`:** Shared stylesheet defining the custom color palette, layout cards, and responsive design rules.
